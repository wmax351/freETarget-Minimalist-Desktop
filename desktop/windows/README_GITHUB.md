# Windows 0.3.12-beta.1

Build from this folder on Windows 11 with Python 3.12 x64 and x86 and Inno Setup 6. See `README_WINDOWS_BUILDS.md` for prerequisites and `BUILD_WINDOWS_X86.md` for the 32-bit build. Use `BUILD_AND_INSTALL_BOTH.bat` to build both architecture-specific installers.

The Windows x86 installer requires a real Windows 10 32-bit compatibility test before release. Generated virtual environments, executables, installer files, and build outputs are intentionally omitted from Git.
