# Windows 0.3.12-beta.1 — source refresh

Updated default logo/app icons, circular appearance swatches and spacing, stacked
Wi-Fi mode descriptions, Korean/Turkish/Vietnamese/Arabic language options, and
Brazilian Portuguese speech locale handling. Target zoom/pan supports touch,
precision touchpads and mouse drag when zoomed. Wi-Fi and USB remain available.
Existing installer IDs and user-data locations are preserved. Cloud sync remains
Apple-only. Windows and on-device audio behavior require native validation.

Build both x64 and x86 with BUILD_AND_INSTALL_BOTH.bat. New installers are not yet
compiled, signed or published; existing GitHub download links remain unchanged.
